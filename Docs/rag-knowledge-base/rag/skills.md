## Programming Languages

Rahul's primary programming languages are JavaScript and Python. He also knows C++.

JavaScript is his day-to-day language for web development — frontend with React/Next.js and backend with Node.js/Express. Python is his language for machine learning work — PyTorch, NumPy, scikit-learn, Pandas, and FastAPI.

## Frontend

React is his primary frontend framework. He has used React 19 (in Skillence), standard React (in SwapHub), and is building his portfolio with Next.js 14 using the App Router. He uses TailwindCSS for styling across his projects.

Next.js gives him SSR, next/image optimisation, and API routes in the same project. He chose it for the portfolio over a plain Vite + React setup because the Vercel deployment story is simpler and the built-in image optimisation matters for performance.

## Backend

Node.js with Express.js is his primary backend for web applications. He has used it in Hisaab Pro, SwapHub, and freelance client work. FastAPI (Python) was used for Skillence's ML-serving backend because Python is the natural language for PyTorch integration.

He works with REST APIs as his default API pattern.

## Machine Learning & AI

PyTorch is his primary ML framework. He trained the Skillence recommendation model in PyTorch — a model that maps 692 skills to 894 occupations.

NumPy is his numerical computing library. Notably, he wrote a custom pure NumPy inference layer for Skillence production serving, replacing the PyTorch runtime to eliminate backend crashes. This means he understands not just how to use ML frameworks, but what they're doing under the hood.

He has also used scikit-learn and Pandas for data processing and the Gemini API for LLM integration (both in Skillence and in the portfolio chatbot). Azure AI was also used in Skillence.

He is currently learning LLM evaluation frameworks — Langfuse and RAGAS — and building RAG pipelines. The portfolio chatbot is a live example of this.

## Databases

SQLite (with encryption) is used in Hisaab Pro. MongoDB with Mongoose is used in SwapHub. He also knows MySQL and PostgreSQL. For vector storage, he uses Supabase with the pgvector extension.

He chose pgvector inside Supabase for the portfolio chatbot's vector database because it means one less service — Postgres handles relational data, full-text search, and vector search in a single query using hybrid search (cosine similarity + BM25).
